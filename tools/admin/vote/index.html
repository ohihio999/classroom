編輯活動

留白表示不限制。設了截止時間後，時間一到前台會自動鎖住不能再投。

照片會自動壓縮後上傳，不用先處理尺寸。標題、說明、連結都可以留白 — 純照片投票（桌曆）留白即可；旅遊景點投票就填景點名稱與 Google Map 連結。改完記得按「儲存選項」。

整份留白 = 不限名單，前台改成讓投票人自己輸入姓名（適合對外或人數不固定的投票）。
有名單時前台是下拉選單，同一個名字只能投一次。

投票明細
