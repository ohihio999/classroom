編輯活動

留白表示不限制。設了截止時間後，時間一到前台會自動鎖住不能再填。
每題可以選幾個、要不要必填，都在「題目設計」分頁裡各題自己設定。

題型：單選／複選／下拉／簡答／問答／線性量表。每題都能設「必填」；選項可以加圖也可以不加圖， 照片會自動壓縮後上傳，不用先處理尺寸。純照片投票（桌曆）把呈現方式設成「圖卡格狀」、標題留白即可； 滿意度問卷用「線性量表」；想收文字意見用「簡答／問答」。改完一定要按「儲存題目」。

整份留白 = 不限名單，前台改成讓填答人自己輸入姓名（適合對外或人數不固定的問卷）。
有名單時前台是下拉選單，同一個名字只能填一次。

填答明細

填答人送出的新選項提案。按「通過」會加進你指定那一題的選項清單（無照片，可再自行補上）。

新增投票活動

只能用英文字母、數字、減號。這會出現在網址：/vote/?poll=desk2027

複製會帶入名單、題目與選項（含照片）與各項開關，但不會複製任何填答。每年開新一屆用這個最快。
