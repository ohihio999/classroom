🗃️ 歸檔（course-collect）
課程散檔收齊、統一改名、搬進 D:\2026_已整理課程
怎麼用
把檔案路徑貼給 Claude Code，最後打「歸檔」
其中至少一個檔的檔名要帶正確課程名稱（當種子），其他檔案會自動找出來。跨磁碟、桌面上的散檔都能收。
命名規格
媒體檔：YYYYMMDD_主題.mp4 / .mp3 / .srt
文字檔：YYYYMMDD_主題_角色.副檔名
mp3 / mp4 / srt 共用同一檔名、不帶尾綴——播放器才會自動載入字幕。
文字檔尾綴：_逐字稿、_摘要、_培訓報告、_心智圖、_心智圖網頁版。
檔名一律不留空格。
它會自動做的事
① 從最長檔名清洗出主題（剝頭尾日期、去空格）
② 以種子時間戳 ±12 小時擴批，找出同一場的其他檔
③ ffprobe 比長度配對媒體檔（時間戳分不開兩場錄影，長度可以）
④ 讀檔案開頭判角色（「摘要總覽」→ 摘要、「概述」→ 培訓報告）
⑤ 列候選清單給你確認
⑥ 去重後移動（不是複製）到 D 槽，寫 _整理紀錄.txt
安全機制
候選清單沒經你確認，不會動任何檔案。
每個資料夾都有 _整理紀錄.txt（原路徑 → 新檔名 + MD5），搬錯可還原。
一律不刪來源殘留，只列出來讓你自己決定。
只做收齊，不轉檔也不產內容。轉檔找 youtube-mp3、轉逐字稿找 groq-transcribe、進 Obsidian 找 course-filing。
🔤 字幕歸檔
Arctime 人工校對版字幕，換掉當初自動產的 srt
怎麼用
在 Arctime 校完字幕、匯出後，跟 Claude Code 說「字幕歸檔」
不用給路徑、不用說是哪一場課，它自己會比對出來。
來源固定
C:\Users\admin\Documents\Arctime Documents\Subtitle Export
怎麼認出是哪一場課
Arctime 匯出檔名一律是 Untitled-subtitle-時間戳.srt，完全沒有資訊，靠檔名認不出來。

所以改用兩項交叉比對：
① 首句文字（srt 第一條字幕內容）
② 末段時間軸（最後一條字幕的時間，應接近影片長度）

兩項都對上才算同一場。校對後條數通常少個一兩條、結束時間早幾秒，屬正常。
它會做的事
① 比對結果先列給你確認
② 刪掉該課程資料夾原有的 srt
③ 校對版移動進去（來源清空），改名成課程檔名
④ 追加寫入 _整理紀錄.txt
比對不上任何課程的字幕會留在來源、列出來問你，不會亂猜。
