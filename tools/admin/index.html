🗃️ 課程散檔歸檔
課程散檔收齊、統一改名、搬進 D:\2026_已整理課程
怎麼用
把檔案路徑貼給 Claude Code，最後打「歸檔」
其中至少一個檔的檔名要帶正確課程名稱（當種子），其他檔案會自動找出來。跨磁碟、桌面上的散檔都能收。
命名規格
媒體檔：YYYYMMDD_主題.mp4 / .mp3 / .srt
文字檔：YYYYMMDD_主題_角色.副檔名
mp3 / mp4 / srt 共用同一檔名、不帶尾綴——播放器才會自動載入字幕。
文字檔尾綴：_逐字稿、_摘要、_培訓報告、_心智圖、_心智圖網頁版。
檔名一律不留空格。
它會自動做的事
① 從最長檔名清洗出主題（剝頭尾日期、去空格）
② 以種子時間戳 ±12 小時擴批，找出同一場的其他檔
③ ffprobe 比長度配對媒體檔（時間戳分不開兩場錄影，長度可以）
④ 讀檔案開頭判角色（「摘要總覽」→ 摘要、「概述」→ 培訓報告）
⑤ 列候選清單給你確認
⑥ 去重後移動（不是複製）到 D 槽，寫 _整理紀錄.txt
安全機制
候選清單沒經你確認，不會動任何檔案。
每個資料夾都有 _整理紀錄.txt（原路徑 → 新檔名 + MD5），搬錯可還原。
一律不刪來源殘留，只列出來讓你自己決定。
只做收齊，不轉檔也不產內容。轉檔找 youtube-mp3、轉逐字稿找 groq-transcribe、進 Obsidian 找 course-filing。
🔤 課程字幕歸檔
Arctime 人工校對版字幕，換掉當初自動產的 srt
怎麼用
在 Arctime 校完字幕、匯出後，跟 Claude Code 說「字幕歸檔」
不用給路徑、不用說是哪一場課，它自己會比對出來。
來源固定
C:\Users\admin\Documents\Arctime Documents\Subtitle Export
怎麼認出是哪一場課
Arctime 匯出檔名一律是 Untitled-subtitle-時間戳.srt，完全沒有資訊，靠檔名認不出來。

所以改用兩項交叉比對：
① 首句文字（srt 第一條字幕內容）
② 末段時間軸（最後一條字幕的時間，應接近影片長度）

兩項都對上才算同一場。校對後條數通常少個一兩條、結束時間早幾秒，屬正常。
它會做的事
① 比對結果先列給你確認
② 刪掉該課程資料夾原有的 srt
③ 校對版移動進去（來源清空），改名成課程檔名
④ 追加寫入 _整理紀錄.txt
比對不上任何課程的字幕會留在來源、列出來問你，不會亂猜。

📸 自動翻頁截圖（本機）
自動按右方向鍵翻頁、定時截圖存 PNG，適合把電子書／簡報整本抓下來
怎麼啟動
按這張卡片右上角的 🚀，瀏覽器問「要開啟 AutoShot 嗎」按允許。
只有這台電腦有效（協定註冊在 HKCU\Software\Classes\autoshot）。手機或別台電腦點 🚀 不會有反應。
也可以直接雙擊桌面的「自動右鍵截圖」捷徑。
操作
啟動後先跳設定選單 → 按確定
F9 開始／暫停　F10 結束　托盤圖示可隨時叫回設定
流程是「按 → 、等 N 秒、截圖、確認寫檔成功、才按下一次」，所以不會翻頁翻在截圖前面。
設定選單四項
① 擷取畫面：列出每台螢幕與長寬，直式會標「（直式）」
② 等待秒數：按 → 之後等幾秒才截圖，可自行輸入小數
③ 張數上限：截滿自動停止，0 = 不限
④ 截滿之後：不做任何事／關機／休眠（倒數 60 秒可取消）
⑤ 存放位置：可打路徑或按「瀏覽…」，不存在會自動建立
預設存 桌面\自動截圖\，檔名 shot_YYYYMMDD_HHMMSS.png，同秒會自動加流水號不覆蓋。
注意
多螢幕時選單台螢幕、別選「全部螢幕合併」——虛擬桌面一定是矩形，直式橫式混排必然帶黑邊。
螢幕轉直式或改解析度不必回選單重選，v5.0 每張截圖前都會重讀尺寸。
連續 3 次截圖失敗會自動停止，不會繼續空翻頁。
腳本在 classroom\auto-screenshot\auto-screenshot.ahk，需要 AutoHotkey v2。
🖼️ OpenSlideX 簡報（本機）
一份簡報＝本機一個資料夾＋一個 presentation.mdx，可以叫 AI 直接改，改完匯出 PPTX／HTML
① 先啟動服務
cd /d D:\2026_簡報工具 && npm run dev
貼到「命令提示字元」執行。第一次會多花十幾秒打包，出現 http://127.0.0.1:4172/workspace 就好了。這個黑視窗不能關，關了網頁就斷線。
② 開啟編輯器
開啟 Workspace（127.0.0.1:4172）
只有這台電腦有效，手機或別台點了不會有反應。左邊是簡報清單，可開空白檔或套內建範本（Summer Time Report／Moodboard），改完即時預覽。
③ 叫 AI 改簡報（MCP，已裝好）
Claude Code、Codex、Claude Desktop 三邊都已註冊 open_slidex_workspace，直接下指令就好，例如：
「用 open-slidex 把 D:\...\某某摘要.md 做成 12 頁簡報」
「把第 5 頁標題改小一點，圖換成 assets 裡那張」
AI 拿到六個工具：選簡報、讀原始碼／素材、匯入 PPTX／HTML 舊檔、找圖轉圖、審查、編輯。
提交前系統會自動做結構驗證＋渲染檢查，不合格會退件重修，所以不會把版面改爛。
MCP 是新裝的，Claude Code／Codex 要重開一次才吃得到。
④ 檔案在哪、怎麼匯出
D:\2026_簡報工具\open-slidex-workspace\<簡報名>\presentation.mdx
每份簡報自帶 assets\（圖）、knowledge\（你丟給 AI 參考的筆記／PDF／CSV）。
匯出：npm run open-slidex -- export <檔案> --format pptx --out 檔名.pptx（format 可選 pptx／html／mdx）。
更新版本：在 D:\2026_簡報工具 執行 git pull 再 npm install。
來源 github.com/zz41354899/open-slidex（MIT）。完全本機、不需帳號，簡報不會上雲。
📄 圖片合併 PDF（本機）
整個資料夾的圖 → 一份 PDF，圖檔同時重新編號歸檔
這個 Skill 會做什麼（5 個步驟）
① 掃描：以你選的那張圖所在的資料夾為範圍，掃出所有圖檔
支援 jpg／jpeg／png／webp／bmp／tif／tiff；不進子資料夾，非圖檔不理會。
用自然排序——1, 2, 10 排成 1、2、10，不會變成 1、10、2。

② 決定名稱：下面那格留空就自動命名——認第一張圖的封面書名
用 Groq 視覺模型讀封面，第一張是空白頁或版權頁就往後看，最多看 5 張。
Groq 免費額度一分鐘只認得完兩張圖，撞到限流會自動等幾十秒再試，別急著關視窗。
認到書名後再去博客來搜尋校正成正式書名（副標與標點才會對）。
資料夾與 PDF 命名成 主書名 - 作者，冒號後的副標不帶進檔名（路徑會太長）。
認不出來就整個停下來要你手填，不會亂猜一個名字去改幾百個檔案。
自己填的話就照你填的，不辨識。

③ 建資料夾：在同一層建 原資料夾\你打的名稱\
等 PDF 真的做出來才建，中途失敗不會留一個空殼資料夾。

④ 合成 PDF：照①的順序合成 你打的名稱.pdf 放進去
用 img2pdf 無失真嵌入，維持原解析度與長寬比，不重壓縮。
每 50 張先做一份暫存 PDF 最後才合併，所以幾百張大圖也不會吃爆記憶體。

⑤ 重新命名歸檔：原圖搬進新資料夾並依序改名
名稱_0001.png、名稱_0002.png…（4 位補零，副檔名保留）
是搬移不是複製，跑完原本那層就只剩新資料夾。
① 選一張圖（決定要處理哪個資料夾）
選檔視窗會跳在跑服務的那台電腦上（不是手機）。選哪張都可以，只是用來指定資料夾。
② 資料夾與 PDF 的名稱（留空＝自動辨識書名）
自己填的話不能有 < > : " / \ | ? * 這些字元。
需要本機影音服務在跑（127.0.0.1:8767）；沒開的話按卡片上的 🚀 啟動再回來。
