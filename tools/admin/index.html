🗃️ 課程散檔歸檔

怎麼用

命名規格
媒體檔：YYYYMMDD_主題.mp4 / .mp3 / .srt
文字檔：YYYYMMDD_主題_角色.副檔名
mp3 / mp4 / srt 共用同一檔名、不帶尾綴——播放器才會自動載入字幕。
文字檔尾綴：_逐字稿、_摘要、_培訓報告、_心智圖、_心智圖網頁版。
檔名一律不留空格。
它會自動做的事
① 從最長檔名清洗出主題（剝頭尾日期、去空格）
② 以種子時間戳 ±12 小時擴批，找出同一場的其他檔
③ ffprobe 比長度配對媒體檔（時間戳分不開兩場錄影，長度可以）
④ 讀檔案開頭判角色（「摘要總覽」→ 摘要、「概述」→ 培訓報告）
⑤ 列候選清單給你確認
⑥ 去重後移動（不是複製）到 D 槽，寫 _整理紀錄.txt
安全機制
候選清單沒經你確認，不會動任何檔案。
每個資料夾都有 _整理紀錄.txt（原路徑 → 新檔名 + MD5），搬錯可還原。
一律不刪來源殘留，只列出來讓你自己決定。
只做收齊，不轉檔也不產內容。轉檔找 youtube-mp3、轉逐字稿找 groq-transcribe、進 Obsidian 找 course-filing。

🏷️ 對話名同步
把 Claude Code 對話名對齊 20_專案\_進行中\ 的進度檔名
怎麼用
對 Claude Code 說「同步檔名」
收工流程的「自動 C」也會跑一次，對齊當次的進度檔名。
解決什麼問題
對話名是 Claude Code 在開場前幾回合就算定的，那時候使用者往往還沒講清楚要做什麼， 算出來的名字常常跟最後做的事差很遠。結果就是 /resume 清單裡一排看不出在幹嘛的名字， 跟 vault 的進度檔對不起來。
運作方式
① 找對象：掃 session 紀錄，取每個對話的現用名稱。
② 找進度檔：只認該對話實際用工具動過的進度檔（取出現最多次的）， 避免被開場注入的工作交接內容誤導。
③ 算期望名：進度檔名去掉日期前綴與「-進度」後綴。
④ 先乾跑：列出不一致的清單給使用者看，確認後才寫入。
⑤ 只 append 不改舊資料，寫入前自動備份。
⚠️ 機制限制（重要）
Claude Code 每回合都會寫一筆自己算的對話名，而且不讀檔案。所以：
・進行中的對話改了會被下一回合蓋掉，只有「改完不再發言」才留得住。
・已結束的對話改了就穩——那個檔案不會再被寫入。
因此收工時改是成功率最高的時機，但收工後又講話就會被蓋回去，這時再喊一次「同步檔名」補救。
改完要下次 /resume 或重開清單才看得到新名字。
腳本在 C:\Users\admin\.codex\skills\session-title-sync\（不在本 repo）。 僅 Claude Code 適用——Codex／Hermes／agy 沒有對應的 session 紀錄。

📈 資料圖表（chart）
只要一張圖的時候直接叫它，不必先要一整頁。圖庫只用 @unovis，配色由一份 token 統一
① 怎麼叫它
這組數字幫我畫個趨勢圖 做個圖表看占比 這幾個月的業績做成柱狀圖 加個目標對實際的對照圖
② 你想看什麼，它就挑什麼圖
比較各期間單一數值 → 單系列柱｜趨勢或同期對比 → 多系列折線
同期內多項並排 → 分組柱｜看總量也看組成 → 堆疊柱
目標 vs 實際（同單位）→ 柱加折線｜占比結構 → 甜甜圈（中央放總數）
兩指標關聯但單位不同 → 雙面板共用 X 軸
③ 它會先看資料、必要時回頭問你
量級差太大（目標 800 對實際 92）、只有三個點、單位混在一起，任何圖庫畫出來都會醜。 遇到這種它應該先處理資料（換維度／拆成兩張／改比較基準），而不是硬畫。
缺值用空值而不是補 0——補 0 會讓折線假裝掉到谷底。
④ 什麼時候不該畫圖
要精確查數字的場合用表格，圖是用來看形狀的。
流程、架構、狀態機那種結構不歸它管，走 diagram-design。

🧩 結構圖（diagram-design）
流程、架構、時序、狀態機這類「誰接誰」的圖。手工排版 SVG，不靠 Mermaid
① 怎麼叫它
這個流程幫我畫出來 畫一張系統架構圖 這段流程誰接誰，畫個泳道圖 把這個狀態機畫成圖
② 涵蓋 39 種圖型
流程圖、泳道、時序、狀態機、分層架構、樹狀、依賴、部署、ER、時間軸、甘特⋯⋯ 常用的十二型有現成起手範例，其餘 27 型各有自己的畫法文件，用到才讀。
③ 什麼時候該畫圖，而不是塞表格
有分支、有角色交接、有回頭路、跨區連線的流程，一律畫圖。
原因：表格容許含糊（誰交給誰、哪步要先做都可以不寫），圖不容許。 實測掃 50 份流程頁，14 份把流程塞進表格、只有 5 份畫圖；三組並排給人看，讀者全選圖的版本。
單向直線的步驟鏈不必動用它，一條簡單的流程條就夠。
④ 圖大的時候會多一層探索
六格以上又有分支的圖會掛上互動層：點一格聚焦、追上下游、看兩點之間的路徑、切章節視角。 圖太寬時外層會包成可左右捲動，不會把整頁撐爆。
